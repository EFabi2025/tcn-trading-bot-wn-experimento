## ⚡ **Inicio Rápido**

1. **Instalar dependencias:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Configurar API keys:**
   - Ver [`docs/CONFIGURACION_API_KEYS.md`](./docs/CONFIGURACION_API_KEYS.md)

3. **Ejecutar:**
   ```bash
   python simple_professional_manager.py
   ```
